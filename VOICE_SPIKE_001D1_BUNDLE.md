# Voice Spike 001D-1: Locally Bundled ElevenLabs SDK

## Summary

Replaced CDN-based ElevenLabs SDK loading with a locally bundled solution to eliminate CORS/MIME type errors.

---

## Root Cause

**All CDN attempts failed:**
- ❌ UNPKG: MIME type "text/plain" (UMD build doesn't exist)
- ❌ jsDelivr: CORS/MIME type errors
- ❌ elevenlabs.io/convai-widget: CORS errors

**Conclusion:** `@elevenlabs/client` cannot be reliably loaded from CDN in production

---

## Solution

**Locally bundle the official SDK using esbuild**

1. Install `@elevenlabs/client` as npm dependency
2. Create wrapper module in `frontend/voice-client.js`
3. Bundle with esbuild to `static/js/voice-client.js`
4. Serve from Flask application (no CDN dependency)

---

### 2. frontend/voice-client.js (NEW)

```javascript
import { Conversation } from '@elevenlabs/client';

export async function startVoiceConversation(options) {
    const { signedUrl, onConnect, onDisconnect, onError, onModeChange } = options;
    
    console.log('[VOICE] Starting ElevenLabs conversation with official SDK v1.21.0');
    
    const conversation = await Conversation.startSession({
        signedUrl,
        onConnect: (data) => {
            console.log('[VOICE] Conversation connected:', data);
            if (onConnect) onConnect(data);
        },
        onDisconnect: () => {
            console.log('[VOICE] Conversation disconnected');
            if (onDisconnect) onDisconnect();
        },
        onError: (error) => {
            console.error('[VOICE] Connection error:', error);
            console.error('[VOICE] Error stack:', error.stack);
            if (onError) onError(error);
        },
        onModeChange: (mode) => {
            console.log('[VOICE] Mode change:', mode.mode);
            if (onModeChange) onModeChange(mode);
        }
    });
    
    console.log('[VOICE] Conversation started successfully');
    return conversation;
}

export async function endVoiceConversation(conversation) {
    if (!conversation) return;
    console.log('[VOICE] Ending conversation');
    await conversation.endSession();
    console.log('[VOICE] Conversation ended');
}

console.log('[VOICE] ElevenLabs SDK module ready (v1.21.0)');
```

**Purpose:** Wrapper module that imports official SDK and exposes clean API

## Why This Works

**Problem:** CDN loading fails due to CORS/MIME issues

**Solution:** Bundle SDK locally and serve from Flask

**Benefits:**
1. ✅ No CDN dependency
2. ✅ No CORS issues (same-origin)
3. ✅ No MIME type issues (Flask serves correctly)
4. ✅ Official SDK (not a workaround)
5. ✅ Version controlled (package.json)
6. ✅ Reproducible builds

**Trade-offs:**
1. ⚠️ Requires Node.js/npm for build (dev dependency only)
2. ⚠️ Adds ~100-200KB to static assets
3. ⚠️ Build step required before deployment

**Acceptable because:**
- Build-time dependency only (not runtime)
- Bundle size reasonable for voice feature
- Build step automated in Render
